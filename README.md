# Совет мудрецов

Многопользовательский 3D-городок в лесу. Игроки приносят задачи или приглашают посетителей и обсуждают решения с шестью историческими персонажами. Локальная LLM работает на сервере; клиенты получают реплики по авторизованному WebSocket.

## Запуск

Нужен Node.js 22.13+, установленные зависимости и работающая на сервере Ollama с выбранной моделью. Настройки существующего .env сохраняются.

```bash
# Терминал 1
npm start
# Терминал 2
npm run dev --workspace=apps/frontend
```

Frontend: http://localhost:3000, backend: 2567, Ollama: 127.0.0.1:11434. Другой ноутбук открывает http://IP_СЕРВЕРА:3000. Порты должны быть доступны в LAN и проброшены из WSL при необходимости. Проект не настраивает сетевой экран Windows автоматически. Интернет для игры не нужен; на клиентах достаточно браузера.

## Управление

WASD — ходить, Shift — бег, Space — прыжок. Мышь поворачивает камеру, колесо меняет расстояние, Esc освобождает курсор. E у мудреца — личный разговор, E у стола — совет. C открывает окно совета; отправка вопросов требует находиться у стола. Общий чат игроков доступен отдельно.

R — взять мяч или открыть/закрыть дверь. Q — положить, T — бросить. N у жителя — попросить проводить к залу, повторное N отменяет помощь. G — позвать жителей, F — оставить угощение животным в лесу. Олени преимущественно живут за пределами центральной площади.

Админка сворачивается и не блокирует ходьбу. При вводе в её поле клавиши поступают в поле. Во время разговора с мудрецами ходьба приостановлена.

## Окружение и физика

Зал окружают 22 здания, внешние улицы, площадь, пруд, читальня и школа ремёсел. Модульные дома, лавочки, сосны и текстуры включены локально. См. ASSET_LICENSES.md.

Надписи скрываются стенами. У людей есть коллизионные капсулы. Ближайшие 18 жителей используют анимированные GLB, дальняя толпа — instancing. Проводник проигрывает ходьбу только при фактическом движении.

Открываемые двери и пять мячей имеют общее серверное состояние. Переносимых ящиков больше нет. Физика мячей использует фиксированный шаг 1/60 с, снимки отправляются 20 раз в секунду. Клиент интерполирует состояния и ограничивает предсказание 100 мс, не рассчитывает независимую траекторию.

## Данные

bcrypt и JWT обеспечивают авторизацию до входа в комнату. SQLite хранит аккаунты, подтверждённые позиции, диалоги, память агентов, посетителей, настройки администратора, изменения окружения и положения остановившихся предметов/двери. После аварии восстанавливается последнее подтверждённое сохранение; незаписанное движение между пакетами восстановить нельзя.

БД и .env не входят в обновление и не заменяются версиями товарищей. Существующие данные не сбрасываются.

Карта 16 384 × 16 384 м состоит из 65 536 чанков. Клиент получает не более девяти соседних чанков и заменяет старое окно. Сохранения за новой границей ограничиваются ближайшим краем при входе; исходная БД остаётся в резервной копии обновления.

Каталог и индикатор кэша учитывают файлы ресурсов, сериализованные чанки и резерв. Это не процент всей памяти браузера/GPU. См. NETWORK_AND_CACHE.md.

После изменения ресурсов или геометрии пересчитай каталог:

```bash
npm run world:catalog --workspace=apps/backend
```

## Проверки

```bash
npm run format:check
npm run typecheck
npm test
npm run build
```

Тесты покрывают авторизацию, сохранения SQLite, административные права, приватность чатов, память и маршрутизацию совета, посетителей, изменение мира, жителей, владение мячом, отскоки и двери. LLM в тестах заменяется контролируемым ответчиком; её реальная скорость зависит от серверного компьютера.

Разработческий режим браузерный, с камерой от третьего лица. Полноценный WebXR-сеанс данным обновлением не добавляется.
