# Сеть и кэш мира

Карта конечная: 16 384 × 16 384 м, 256 × 256 чанков по 64 м. Аудит обходит все 65 536 детерминированных чанков и суммирует фактические размеры UTF-8 JSON. Сервер создаёт их по запросу, не хранит весь каталог в оперативной памяти.

Дополнительно считаются все локальные GLB, GLTF, BIN, изображения и исходные определения геометрии. Общие ресурсы полностью учитываются на клиенте, даже когда ещё не загружены. Будущая динамика не добавляется в знаменатель, что делает оценку более строгой.

```
полный_мир = сумма_JSON_всех_чанков + общие_ресурсы
бюджет = floor(полный_мир / 10)
учтённый_кэш = общие_ресурсы + резерв_1_MiB + 2 × байты_снимка
```

Два буфера учитывают одновременное существование старого и нового окна. Резерв покрывает несколько копий динамических сообщений и вспомогательные метаданные. Жители ограничены 162, мячи — пятью, двери — 22. Старые ID жителей удаляются при смене окна. Общая модель игрока также учтена.

Генератор проверяет самое тяжёлое окно среди всех центров карты и дополнительно закладывает 64 KiB на изменения. Сервер и клиент отклоняют превышение бюджета. Клиент сверяет идентификатор каталога, границы и количество объектов. У края карты загружается меньше девяти чанков.

Точные размеры, SHA-256 и бюджет находятся в двух одинаковых WorldCatalog.generated.ts. Пересчёт: `npm run world:catalog --workspace=apps/backend`. Запуск сервера и сборка проверяют актуальность каталога; слишком большой новый ресурс вызовет ошибку.

На проверенной версии HUD показывает около 5,2%, консервативная оценка худшего окна — около 5,4%. В браузере `window.__worldCache` содержит usedBytes, totalBytes, budgetBytes, chunkBytes и catalogId. HTTP `Cache-Control: no-store` для `/models/` предотвращает дополнительный дисковый HTTP-кэш. GLTF и материалы переиспользуются; архитектура и растительность используют instancing.

Это доля сериализованных данных мира и файлов ресурсов, не процент всей RAM/VRAM. Декодированные текстуры, буферы GPU, структуры JavaScript и движок имеют другой размер. Требование именно к физической памяти потребует отдельной единицы измерения и профилирования полного декодированного мира.

JWT проверяется до входа в Colyseus. Перемещения, диалоги и соседние чанки идут по WebSocket. Браузеры не обращаются к Ollama напрямую: ИИ вычисляется сервером. Запросы выбранных мудрецов выполняются последовательно, каждый следующий получает контекст предыдущих реплик.

Для LAN нужны сервер и браузеры клиентов; доступ к WSL через Windows зависит от сетевых настроек ноутбука. На серверном компьютере доступен localhost без Wi-Fi. В игре нет внешних CDN и обращений к интернету.
