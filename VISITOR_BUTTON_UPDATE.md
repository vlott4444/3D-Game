# Обновление: кнопка «Отпустить посетителя»

Основа — frontend до мержа с веткой Roma.

Изменены три файла:

- `apps/frontend/src/ui/DialoguePanel.tsx` — кнопка «Отпустить посетителя» рядом с «Пригласить посетителя».
- `apps/frontend/src/style.css` — единый стиль всех HTML-кнопок как у «В зал» и «Выйти».
- `apps/backend/src/agents/VisitorManager.ts` — разрешено отпускать посетителя без предварительного ответа мудреца.

Кнопка активна, когда посетитель приглашён, разговор не занят, игрок находится рядом со столом. После нажатия посетитель уходит с анимацией выхода.

Запуск: `npm ci`, `npm start`; отдельный терминал `npm run dev -w apps/frontend`.

В ZIP нет node_modules, токенов и файлов SQLite. При обновлении действующего проекта сохраните свою базу данных.
