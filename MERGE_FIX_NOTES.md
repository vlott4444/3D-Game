# Исправление конфликта веток

Сохранено из пользовательского интерфейса: стилизованная травяная земля, освещение, объекты мира, модель `pointer.glb` над столом и анимация, а также модель игрока `urotsuki.glb` с анимациями для локального и сетевых игроков. Сохранена общая стилистика кнопок.

Взято из рабочей версии Roma: серверная комната и обработчики авторизации, сохранения, взаимодействия с миром, история диалогов, серверные NPC, административная панель и клиентские интерфейсы взаимодействия. Сохранён функционал приглашения/отпускания посетителя через окно совета.

Проверки: `npm run typecheck -w apps/frontend` и `npm run typecheck -w apps/backend` — без ошибок. `npm run build -w apps/backend` — успешно. `vite build` и тесты не смогли стартовать в Linux-песочнице из-за macOS ARM64 бинарников в исходном node_modules; эти зависимости исключены из архива. Для локальной установки выполните `npm ci` на вашей машине.

Нельзя переносить `node_modules` между macOS и Linux. Архив не содержит SQLite-файлы, `.env` и артефакты сборки. Сначала сохраните свою базу данных и конфигурацию перед заменой проекта.
