# Замена игрока на Urotsuki

- `apps/frontend/public/models/urotsuki.glb` — модель, предоставленная пользователем.
- `apps/frontend/src/game/Player.tsx` — вместо кубического персонажа загрузка GLB, анимации Idle / Walking, плавные переходы, ускоренная анимация бега, тени. Для каждого игрока клонируется скелет.
- `apps/frontend/src/game/RemotePlayers.tsx` — другие подключённые игроки тоже отображаются моделью Urotsuki.
- `PlayerController.tsx` и `FollowCamera.tsx` оставлены без изменений: WASD, Shift, прыжок, движение относительно камеры, ускоренное падение, сохранение позиции и взаимодействия работают по существующей логике.
- Физический CapsuleCollider также оставлен прежним.

После распаковки из корня проекта: `npm ci`, `npm start`; отдельно `npm run dev -w apps/frontend`.

Примечание: визуальный масштаб/ориентация модели подобраны по метаданным GLB; браузерный рендер не проверялся.
